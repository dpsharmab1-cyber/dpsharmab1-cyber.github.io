How many kinds of packaging are there?

There is no single world list. The corrugated-box code (FEFCO) has around 200 numbered styles in nine series. The folding-carton code (ECMA) sorts cartons into six style groups (A–F). Flexible packaging, bottles, cans, tubes, cups and labels each add their own formats on top. Most of those styles are small variations of a few base structures.

This library lists the pack types people actually order, grouped by product, and maps each one to a parametric structure. Sizes are typical starting points; check them with your printer or converter.
