Motionmotion.css · motion.js · GSAP on the site

Unhurried and weightless: worlds float and sway, the emblem turns, type rises out of a mask. Every loop is a class with custom properties; reduced motion stops them all.

.rp-sway--deg 2.5° · --dur 11s · alternate

.rp-spin / .rp-spin-revstar 160s, rings 120s / 90s

.rp-glow + .rp-breathe3.2s glow, 6s breath

.rp-cometa streak every few seconds
